# 项目阶段状态快照（2026-09-22）

本文是当前代码仓库的简明状态入口。详细过程、证据位置和阶段决策以
`docs/mission_list.md` 及各实验目录内的哈希审计为准。

## 1. 项目目标

本项目解决 PA-MOAP 的教学方法分配阶段：上游已经选定知识点，本阶段为每个知识点
从 11 种教学方法中选择一种。目标同时考虑教学效果、学生偏好、教师偏好、方法多样性
和方法占比软约束，并比较启发式、精确优化、混合求解和 PPO。

当前新版研究覆盖四类拓扑和九个规模组，开发实例的节点规模约为 60–1000。

## 2. 当前冻结主线

- 冻结目标：`main_no_reference__h0.65__c0.35__be1.00__bc1.00`。
- 目标权重：教学效果 0.35，学生偏好 0.325，教师偏好 0.325。
- 多样性设置：归一化熵下限 0.65，单方法占比上限 0.35。
- PPO 模型：`legacy_separate_v1`，隐藏维度 64。

- seed0 参考 checkpoint：run03 update60。
- 冻结推理：确定性 masked argmax，`max_steps=512`、`patience=32`，从
  effect-greedy 初解出发并返回 best feasible assignment。

## 4. 当前主要结论

- 冻结 PPO 在 Stage7 质量样本上的 mean/P90 exact gap 为约
  `0.4580%/0.7781%`。
- 真批推理有效：同内容多偏好 batch1→128 吞吐约提升 12.83 倍；新内容新偏好
  分桶负载约提升 6.85 倍；混合规模 padding 负载约提升 2.04 倍。
- 当前数据不支持“冻结 PPO 的总体服务效率优于合理基线”：scalarized greedy 在开发集上
  同时具有更低 gap 和更高吞吐。
- PPO 能响应学生偏好和冲突画像的一部分变化，但对 teacher-only 变化仍为零响应。
  精确模型和局部搜索存在有效改进，因此该问题集中在策略动作排序和轨迹形成，而不是
  目标函数没有响应空间。
- A/B/C/D/E 修复分支均未通过预登记门槛，已经关闭且未并入主线。
- 动态偏好 Phase A 未达到 Phase B 门槛，状态为
  `stop_after_phase_a_no_signal`。

这些结论来自已经查看和反复用于开发的四拓扑数据，不能表述为全新独立确认。

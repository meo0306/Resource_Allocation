

## ① 全局规模信息（Global Instance Information）

**功能定位**：
- 定义算例的基本规模与随机性来源
- 不直接参与优化，仅作为实例元信息

**规范模板**：
```text
************************************************************************
Instance name                 : <instance_name>
Description                   : <optional free text description>
Nodes (incl. supersource/sink): <num_nodes_total>
Random seed                   : <seed>
************************************************************************
```

**字段说明**：
- `Instance name`：算例唯一标识
- `Description`：可选描述（生成规则、实验分组等）
- `Nodes (incl. supersource/sink)`：节点总数（包含虚拟起点与终点）
- `Random seed`：用于算例生成过程的随机种子

## ② 先修关系（Precedence Relations）

**功能定位**：
- 定义节点之间的先后依赖关系
- 构成调度问题的 DAG 结构核心

**规范模板**：
```text
************************************************************************
PRECEDENCE RELATIONS:
nodnr.  #successors  successors
<j>     <k>          <s1> <s2> ... <sk>
************************************************************************
```

**字段说明**：
- `nodnr.`：节点编号（1 到 `num_nodes_total`）
- `#successors`：直接后继节点数量
- `successors`：后继节点编号列表

**结构约定**：
- 虚拟起点：无前驱
- 虚拟终点：无后继
- 整体必须构成 DAG

--------------------------------------------

## ③ 节点属性（Node Attributes）

**功能定位**：
- 描述每个节点的类别、价值属性与成本属性
- 是目标函数与约束建模的主要数据来源

**规范模板**：
```text
************************************************************************
NODE ATTRIBUTES:
nodnr.  <type>  <p_1>  <p_2>  <p_3>  <q_1>  <q_2>  <q_3>
<j>     <type_k> <p_j1> <p_j2> <p_j3> <q_j1> <q_j2> <q_j3>
************************************************************************
```

**字段说明**：
- `<type>`：节点类别（如基础 / 核心 / 拓展等离散标签）
- `<p_k>`：价值属性，依次表示：
  1. 重要性（Importance）
  2. 时效性（Timeliness）
  3. 可测性（Measurability）
- `<q_k>`：成本属性，依次表示：
  1. 教学时长（Teaching Time）
  2. 认知负担（Cognitive Load）
  3. 外部资源需求（External Resource Demand）

**设计约定**：
- 所有属性为节点级静态属性
- 属性值为数值型（连续或离散由生成器定义）

--------------------------------------------

## ④ 成本上限（Cost Capacities）

**功能定位**：
- 定义项目级的全局成本/预算约束
- 与节点成本属性通过累积关系关联

**规范模板**：
```text
************************************************************************
COST CAPACITIES:
<q_1>  <q_2>  <q_3>
<Q_1>  <Q_2>  <Q_3>
************************************************************************
```

**字段说明**：
- `<Q_k>`：对应成本维度的容量上限
- 依次对应：
  1. 总教学时长上限
  2. 总认知负担上限
  3. 总外部资源使用上限
